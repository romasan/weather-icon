# Погода на иконке (Android 15+)

Приложение ищет город через Open-Meteo Geocoding API, показывает текущую температуру и погодные условия через WeatherAPI.com, сохраняет последний ответ и обновляет иконку приложения.

## WeatherAPI.com

Текущая погода загружается с `https://api.weatherapi.com/v1/current.json` по координатам выбранного города. Поиск города оставлен на Open-Meteo Geocoding API. Ключ не хранится в исходниках: задайте `weatherapi.key=ВАШ_КЛЮЧ` в локальном `local.properties` рядом с `settings.gradle.kts`. При сборке ключ передаётся в APK через `BuildConfig`.

## Обновления и значок

Иконки приложения переключаются через `activity-alias`: подготовлены статические варианты для температур от −99 до +99 градусов и шести типов условий: ясно, дождь, снег, смешанные осадки, гроза и туман. Пока приложение открыто, погода запрашивается каждые 10 минут. Фоновый периодический запуск настроен на минимальные 15 минут WorkManager; Android может его задержать.

## Сборка

Требуются Android SDK Platform 35, Build Tools 35.0.0, Gradle 8.11.1 и JDK 17. Инструменты разработчика находятся в `work/tools` рядом с проектом. Сборка: `gradle assembleDebug` из каталога `WeatherIconAndroid`.
